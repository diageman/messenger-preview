# BROWSER VERIFICATION GUIDE

## ИНСТРУКЦИЯ ПО ПРОВЕРКЕ

### Подготовка

1. **Открой 2 браузера** (или 1 обычный + 1 инкогнито):
   - Browser A: http://localhost:5173 (или production URL)
   - Browser B: http://localhost:5173 (или production URL)

2. **Залогинься под разными пользователями**:
   - Browser A: user1@test.local / password
   - Browser B: user2@test.local / password

3. **Создай direct chat между пользователями**:
   - В Browser A: Контакты → выбери user2 → Чат
   - В Browser B: должен появиться чат с user1

4. **Открой консоль в каждом браузере** (F12):
   - Вставь скрипт из `scripts/browser-verification.js`
   - Нажми Enter
   - Введи `VERIFICATION.start()`

---

## ТЕСТ 1: Incoming Realtime Latency

**Цель:** Сообщение должно появляться сразу (<1s)

**Шаги:**
1. Browser A: отправь сообщение "Привет"
2. Browser B: смотри на активный чат
3. Засеки время от отправки до появления

**Ожидай:**
- ✅ Сообщение появляется в Browser B сразу (<1s)
- ✅ Не нужно обновлять страницу
- ✅ Не нужно ждать polling

**Провал:**
- ❌ Сообщение появляется через 3-10 секунд
- ❌ Нужно ждать polling
- ❌ Нужно обновлять страницу

---

## ТЕСТ 2: Chat List vs Active Chat Sync

**Цель:** Сообщение должно появляться одновременно везде

**Шаги:**
1. Browser A: отправь сообщение
2. Browser B: смотри одновременно на:
   - Chat list (слева)
   - Active chat (справа)

**Ожидай:**
- ✅ Сообщение появляется в chat list И active chat одновременно
- ✅ Разница <500ms

**Провал:**
- ❌ Сначала в chat list, потом в active chat (разница >1s)
- ❌ Только в chat list, в active chat не появляется

---

## ТЕСТ 3: Active Chat Flicker

**Цель:** Окно чата не должно мигать

**Шаги:**
1. Browser A: открой direct chat
2. Browser A: оставь открытым на 20 секунд
3. Browser B: отправь 3-4 сообщения
4. Browser A: смотри на окно чата

**Ожидай:**
- ✅ Сообщения остаются на экране
- ✅ Нет спиннеров "Загрузка..."
- ✅ Нет пустого экрана
- ✅ Нет визуального мигания

**Провал:**
- ❌ Сообщения исчезают и появляются снова
- ❌ Показывается спиннер
- ❌ Пустой экран на мгновение
- ❌ Визуальное мигание

---

## ТЕСТ 4: Chat List Flicker

**Цель:** Список чатов не должен мигать

**Шаги:**
1. Browser A: открой чаты
2. Browser B: отправь сообщение
3. Browser A: смотри на chat list

**Ожидай:**
- ✅ Chat list остаётся видимым
- ✅ Нет "Нет чатов" empty state
- ✅ Нет исчезновения списка

**Провал:**
- ❌ Показывается "Нет чатов"
- ❌ Список исчезает на мгновение
- ❌ Визуальное мигание

---

## ТЕСТ 5: Identity Consistency

**Цель:** Имя и avatar должны совпадать везде

**Шаги:**
1. Browser A: открой direct chat с user2
2. Посмотри в ChatList (слева):
   - Имя: _______
   - Avatar initials: _______
3. Посмотри в header (справа):
   - Имя: _______
   - Avatar initials: _______

**Ожидай:**
- ✅ Имя в ChatList = Имя в header
- ✅ Avatar initials совпадают
- ✅ Не показывается "Сотрудник" или "?"

**Провал:**
- ❌ Разные имена
- ❌ Разные initials
- ❌ Показывается "Сотрудник" или "?"

---

## ТЕСТ 6: Unread Badge

**Цель:** Badge должен работать корректно

**Шаги:**
1. Browser A: отправь сообщение
2. Browser B: НЕ открывай чат
3. Посмотри на chat list

**Ожидай (Browser B):**
- ✅ Жёлтый badge с цифрой "1"

**Шаги:**
4. Browser B: кликни на чат (открой)
5. Посмотри на chat list снова

**Ожидай (Browser B):**
- ✅ Badge исчез (0)

**Провал:**
- ❌ Badge не появляется
- ❌ Badge не исчезает после открытия
- ❌ Badge показывает неправильное число

---

## ТЕСТ 7: Autoscroll (ОБЯЗАТЕЛЬНО)

**Цель:** Новые сообщения должны быть видны без ручной прокрутки

**Шаги:**
1. Browser A: открой direct chat
2. Browser A: проскролль вниз (к последним сообщениям)
3. Browser B: отправь сообщение
4. Browser A: смотри на active chat

**Ожидай:**
- ✅ Новое сообщение видно сразу (автоскролл вниз)
- ✅ Не нужно крутить мышкой

**Шаги:**
5. Browser A: отправь своё сообщение
6. Browser A: смотри на active chat

**Ожидай:**
- ✅ Твоё сообщение видно сразу
- ✅ Автоскролл работает

**Провал:**
- ❌ Нужно вручную скроллить вниз
- ❌ Сообщение появляется выше видимой области
- ❌ Нужно крутить мышкой чтобы увидеть

---

## ТЕСТ 8: Combined Flow (End-to-End)

**Цель:** Полный сценарий работы мессенджера

**Шаги:**
1. Browser A: отправь "Привет, как дела?"
2. Browser B: ответь "Нормально, спасибо!"
3. Browser A: отправь "Отлично!"
4. Browser B: отправь ещё 2 сообщения подряд
5. Оба: подождите 15 секунд
6. Оба: отправьте ещё по сообщению

**Ожидай:**
- ✅ Все сообщения появляются сразу
- ✅ Нет задержек >1s
- ✅ Нет мигания
- ✅ Chat list обновляется
- ✅ Unread badges работают
- ✅ Autoscroll работает
